///////////////////////////////actualizar status de los cambios en remoto//////////////////
1. fetch: consultar y descargar cambios del remoto
git fetch origin

////////////////////////////////////fusionar ramas///////////////////////////////
2. merge: incorporar cambios de otra rama a la actual
Imagina que estás en feature/joseph y quieres incorporar los cambios de develop:

git checkout feature/joseph
git fetch origin
git merge origin/develop

//////////////////////////////////////decargan cambios de una misma rama///////////////
3. pull: fetch + merge
Si estás en develop y quieres descargar los últimos cambios de GitHub:

git checkout develop
git pull origin develop
